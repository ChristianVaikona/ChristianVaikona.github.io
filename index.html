Projects

Selected work

Elevator Simulator

An elevator simulation system for a multi-floor building, modeling how different elevator types respond to passenger calls, how calls are assigned, and how cars move over repeated simulation rounds.

Built to practice object-oriented design: abstraction, inheritance, interfaces, and polymorphism across object types that share behavior but follow specialized rules. The simulator includes multiple elevator types, two scheduling strategies, and a control loop that assigns calls, moves elevators, and reports system state until the simulation completes.
